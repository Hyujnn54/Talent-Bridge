ARCHITECTURE LOGIQUE GLOBALE MVC

1) VUE GLOBALE
Le projet suit une architecture MVC (Model - View - Controller) avec JavaFX.
- View: ecrans FXML et composants UI.
- Controller: gestion des actions utilisateur, navigation, validation et orchestration.
- Model: entites metier et structures de donnees.
- Service: logique metier, acces base de donnees, appels API externes, IA, email.
- Utils: session, contexte utilisateur, securite, navigation, helpers techniques.

2) FLUX GLOBAL
- L utilisateur interagit avec un ecran FXML.
- Le Controller recupere les donnees de formulaire et declenche la logique.
- Le Controller appelle un ou plusieurs Services.
- Les Services lisent/ecrivent les Models via la base de donnees ou APIs.
- Le Controller met a jour la View (tables, cartes, statistiques, alerts).

10) RESUME
L architecture est modulaire par gestion metier. Le MVC est respecte:
- Views pour presentation,
- Controllers pour orchestration UI,
- Services pour logique metier/integrations,
- Models pour donnees metier,
avec une couche Utils transversale pour session, securite et infrastructure.
